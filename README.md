# Phenol LMS — Dr. Omar Magdi

المنصة التخصصية في شرح الكيمياء والمواد العلمية للدكتور عمر مجدي (Dr. Omar Magdi).

## الهوية والتقنيات
- **Frontend / Framework:** Next.js 14 (App Router) + React 18 + TypeScript
- **Styling:** Tailwind CSS (Burgundy & Champagne Gold Luxury Theme)
- **Deployment:** Vercel (Hobby Tier - Free)
- **Icons:** Lucide React

## تشغيل المشروع محلياً
```bash
npm install
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)
