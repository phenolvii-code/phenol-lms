# PHENOL LMS — دليل التتبع الجنائي ومكافحة التسريب (Leak Playbook)

> **خاص بدكتور عمر مجدي — إدارة منصة PHENOL ACADEMY**  
> هذا الدليل يشرح كيفية تحديد هوية أي شخص يقوم بتسريب مقطع فيديو أو صورة من محاضرات الكيمياء، والإجراءات الفورية لإيقافه ومساءلته خلال 60 ثانية.

---

## 1. كيف يتم كشف هوية المسرب من أي مقطع أو لقطة شاشة؟

كل طالب يشاهد أي محاضرة على المنصة يظهر على شاشته **علامة مائية جنائية ثلاثية (Triple Forensic Watermark)**:
1. **الاسم الكامل للطالب** (مثل: `محمد أحمد`).
2. **الكود الأكاديمي الحصري المولد من الداتابيز** (صيغة: `PH-XXXXX` مثل `PH-48210`).
3. **آخر 4 أرقام من رقم الهاتف المسجل** (مثل: `TEL: ...7890`).
4. **شريط كودي دقيق في زاوية الشاشة**:  
   `PHENOL FORENSIC WATERMARK // PH48210`

### خصائص العلامة المائية المقاومة للتحايل:
* **متحركة ديناميكياً:** تنتقل كل 10 ثوانٍ بين 5 مواضع مختلفة (الزوايا الأربع والمنتصف العائم) لمنع قص الشاشة (Anti-Cropping).
* **مقاومة لضغط الفيديو:** الخط أبيض عالي التباين مع ظل أسود مزدوج (`text-shadow`) يظل واضحاً ومقروءاً حتى بعد إعادة ضغط الفيديو على تليجرام أو واتساب.
* **حساس حظر التلاعب (`MutationObserver`):** لو حاول الطالب فتح أدوات المتصفح (Inspect Element) لحذف عنصر الووترمارك أو إخفائه (`display: none` أو `opacity: 0`)، المشغل يكتشف ذلك في أجزاء من الثانية ويوقف الفيديو فوراً وتتحول الشاشة إلى سوداء.

## 2. خطوات تتبع المسرب في قاعدة البيانات (خلال 30 ثانية)

بمجرد العثور على مقطع مسرب أو صورة على تليجرام/فيسبوك:

### الخطوة أ: البحث عن الطالب بالكود الأكاديمي
افتح **Supabase SQL Editor** واكتب:
```sql
SELECT id, name, email, phone, academic_code, academic_track, registered_at
FROM public.registered_students
WHERE academic_code = 'PH-XXXXX';
```
*(استبدل `PH-XXXXX` بالكود الظاهر في الفيديو).*

### الخطوة ب: البحث بآخر 4 أرقام من الهاتف (لو كان الكود مقصوصاً)
لو ظهر فقط آخر أرقام الهاتف:
```sql
SELECT id, name, email, phone, academic_code
FROM public.registered_students
WHERE phone LIKE '%7890';
```

### الخطوة ج: فحص سجل المشاهدات الدقيق (`media_access_log`)
لمعرفة توقيت فتح المسرب للمحاضرة بدقة متطابقة مع توقيت الفيديو:
```sql
SELECT m.accessed_at, r.name, r.email, r.phone, r.academic_code
FROM public.media_access_log m
JOIN public.registered_students r ON r.id = m.user_id::text
WHERE m.lesson_id = 'معرف_الدرس'
ORDER BY m.accessed_at DESC;
```

## 3. عقوبة وإيقاف الحساب فورياً (1-Click Revocation)

بمجرد تحديد هوية المسرب، قم بتنفيذ هذا الأمر الفوري في SQL:

```sql
-- 1. إلغاء تفعيل الطالب من كافة الكورسات فوراً
UPDATE public.course_enrollments
SET status = 'REJECTED'
WHERE student_id = 'معرف_الطالب_UUID';

-- 2. إنهاء كافة جلسات أجهزته المسجلة لطرده لحظياً
DELETE FROM public.user_sessions
WHERE user_id = 'معرف_الطالب_UUID'::uuid;

-- 3. حظر الطالب نهائياً من تسجيل الدخول إلى المنصة
UPDATE auth.users
SET banned_until = '2099-01-01 00:00:00+00'
WHERE id = 'معرف_الطالب_UUID'::uuid;
```

بمجرد تنفيذ هذا الأمر:
* يتوقف أي فيديو يعمل لدى الطالب فوراً.
* لا يستطيع فتح أي درس أو ملزمة PDF.
* يتم تسجيل خروجه من جميع أجهزته ولن يستطيع الدخول مجدداً.

## 4. الحماية المطبقة على مشغل الفيديوهات (Video Player Shield)

1. **حظر كليك يمين:** معطل تماماً في واجهة المشغل لمنع فحص العناصر.
2. **درع النقر العازل (Click-Jacking Shield):** تم وضع طبقات شفافة فوق شعار يوتيوب وزر المشاركة وزر القناة، بحيث إذا ضغط الطالب على الشاشة، يتوقف الفيديو أو يشتغل فقط، ولا يمكن نقله لخارج المنصة أو فتح رابط يوتيوب في تبويب جديد.
3. **حصر الأجهزة (Max 2 Devices):** كل طالب مسموح له بجهازين فقط كحد أقصى مسجلين في جدول `user_sessions`. في حال مشاركة حسابه مع زميل ثالث، يتم طرد الجهاز الأقدم تلقائياً.
