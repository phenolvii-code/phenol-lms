# PHENOL LMS — دليل الإعداد والتشغيل السحابي (Setup & Maintenance Guide)

> **خاص بدكتور عمر مجدي — منصة PHENOL ACADEMY للكيمياء**  
> المنصة تعمل الآن بكفاءة متناهية وأمان عالي بتكلفة تشغيل **0 دولار شهرياً ($0/month)**.

---

## 1. البنية التحتية للمنصة (Production Stack)

| المكوّن | الخدمة | التكلفة | الوظيفة |
|---|---|---|---|
| **الواجهة والتطبيق** | Vercel Hobby (Next.js 14) | مجاناً ($0) | استضافة المنصة السريعة عالمياً |
| **قاعدة البيانات والحماية** | Supabase Postgres (Frankfurt eu-central-1) | مجاناً ($0) | حفظ الطلاب، الكورسات، والصلاحيات مع تشفير RLS |
| **المشغل والووترمارك** | مشغل كيميائي مخصص مع حماية جنائية | مجاناً ($0) | علامة مائية متحركة + درع منع النقر + منع التلاعب |
| **حفظ استمرارية السيرفر** | GitHub Actions Cron (`keepalive.yml`) | مجاناً ($0) | منع إيقاف Supabase التلقائي بعد الخمول |

---

## 2. ميزة الاستمرارية التلقائية (Supabase 24/7 Keepalive)

قاعدة بيانات Supabase في الخطة المجانية تتوقف تلقائياً إذا مر 7 أيام دون أي استعلام.  
قُمنا بحل هذه المشكلة جذرياً ومجاناً:
* تم إنشاء أوتوميشن GitHub Action في `.github/workflows/keepalive.yml`.
* يقوم بإرسال إشارة خفيفة كل 4 أيام إلى قاعدة البيانات، مما يجعلها **مستيقظة ونشطة للأبد 24/7** دون أي تدخل منك.

---

## 3. إعداد البريد الإلكتروني الحقيقي (Custom SMTP) — خطوة موصى بها

لحماية المنصة من التسجيل بإيميلات وهمية وضمان وصول إشعارات التفعيل للطلاب:
يمكنك تفعيل خادم بريد مجاني تماماً خلال 3 دقائق:

1. سجل حساباً مجانياً في **[Resend.com](https://resend.com)** (يعطيك 3,000 إيميل مجاني شهرياً) أو **[Brevo.com](https://brevo.com)** (300 إيميل يومياً مجاناً).
2. افتح لوحة تحكم **Supabase** ➔ اذهب إلى **Project Settings** ➔ **Authentication**.
3. انزل إلى قسم **SMTP Settings** وفعّل الخيار:
   * **Host:** `smtp.resend.com` (أو الخاص بـ Brevo)
   * **Port:** `465` أو `587`
   * **User:** `resend` (أو إيميلك في Brevo)
   * **Password:** الـ API Key الخاص بك.
   * **Sender Email:** `notifications@phenol.academy` (أو إيميلك الرسمي).
4. اضغط **Save**. الآن جميع رسائل تأكيد الحساب وكلمات المرور ستصل للطلاب بروابط حقيقية ورسمية.

## 4. دورة حياة الطالب في المنصة (Student Lifecycle)

```
[طالب يسجل حسابه] ➔ [كود أكاديمي فريد PH-XXXXX] ➔ [يطلب تفعيل الكورس]
                                                          │
                                                          ▼
                                            [يظهر في داشبورد د. عمر]
                                                          │
                                         [د. عمر يضغط Approve]
                                                          │
                                                          ▼
                        [RPC: set_enrollment_status('ACTIVE') ينفذ في Postgres]
                                                          │
                                                          ▼
                                            [تفعيل المحاضرات والمشاهدة]
                                    [الووترمارك يطبع اسمه ورقمه وكوده على الفيديو]
```

## 5. إدارة المحتوى والكورسات

* **إضافة كورس جديد:** من الداشبورد اضغط **Create Course**، وسيتم حفظ الكورس مباشرة في جدول `courses` السحابي.
* **إضافة محاضرة:** افتح الكورس واضغط **Add Lecture** وضع رابط الفيديو واسم المحاضرة، وسيتم حفظ المحاضرة وحجب رابط الفيديو عن غير المشتركين.
* **في حالة تسريب أي فيديو:** راجع الدليل الميداني في `docs/LEAK-PLAYBOOK.md` لتحديد هوية الطالب وطرده خلال 30 ثانية.
